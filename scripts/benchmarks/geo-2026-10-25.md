# Coût local de la géolocalisation — 25 octobre 2026

Protocole : `node scripts/benchmarks/run.mjs 30 scripts/benchmarks/geo-2026-10-25.json full:1000,full-no-geo:1000`. Serveur PHP de développement, quatre workers ; MariaDB 11.4.8 dans le conteneur de test isolé, 2 vCPU et 1 Gio. PHP 8.5.7 sur Apple M1. Les deux parcours utilisent le collecteur complet ; le second force un chemin MMDB absent. L'IP synthétique publique est 8.8.8.8 pour provoquer une vraie lecture pays. Chaque profil dure 30 secondes à 1 000 événements/minute, soit 500 événements. Le cache array désactive l'effet du quota d'une unique IP synthétique.

| Profil | Confirmés | P50 | P95 | P99 | Pic PHP alloué |
| --- | ---: | ---: | ---: | ---: | ---: |
| MMDB DB-IP Lite incluse | 500 / 500 | 19,80 ms | 52,77 ms | 153,57 ms | 10 Mio |
| Base absente | 500 / 500 | 21,66 ms | 45,23 ms | 245,92 ms | 2 Mio |

Aucune erreur réseau ou SQL observée. Les 1 000 événements confirmés ont été consolidés exactement une fois ; rapport sur 100 lectures, P95 local 5,03 ms. Différence P95 observée : +7,54 ms avec MMDB ; le P50 plus faible et le P99 plus élevé du parcours sans base montrent le bruit de cette comparaison séquentielle courte. Ce n'est pas une estimation universelle du surcoût.

Le lecteur PHP augmente le pic alloué observé d'environ 8 Mio. Requalifier sur les limites mémoire et I/O d'un hébergement réel, avec WordPress voisin et base volumineuse. Ces mesures ne valident ni Apache, ni LiteSpeed, ni la capacité des quotas distribués.
